# EKORUSTIKA DATA HUB 1.0 (MVP)
Centralno upravljačko sučelje EKORUSTIKA GROUP. PWA, GitHub Pages.
- Tekstualni podaci: localStorage (ključ `ekorustika-datahub-v1`), JSON izvoz/uvoz.
- Mediji (MP4, fotografije): IndexedDB `ekorustika-datahub-media`, odvojeno od teksta.
- Nema tajni, API ključeva ni naplate u frontendu. DATA CORE integracija: kasnije preko Cloudflare Worker API-ja.
